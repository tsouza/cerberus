# Adopters

Organizations that run cerberus are listed below.

| Organization                        | Stage      | Use                                                                       |
| ----------------------------------- | ---------- | ------------------------------------------------------------------------- |
| [ONZACK AG](https://www.onzack.com) | Staging    | Query gateway between Grafana and ClickHouse in staging and test clusters |
| [Squid AI](https://getsquid.ai)     | Production | Query gateway between Grafana and a ClickHouse observability store        |

## Adding your organization

Open a pull request that adds a row to the table, in alphabetical order by organization name. Each
row names the organization, the stage it runs cerberus at (`Production`, `Staging` or `Evaluation`),
and a one-line description of what it uses cerberus for. The pull request is opened by someone who
can speak for the organization, or links to that person's written consent.
